# IPHONE-POO-SIMULATION

A Java project that simulates the core functionalities of an iPhone using Object-Oriented Programming (OOP) concepts such as **encapsulation, abstraction, inheritance, and polymorphism**.

---

## 🚀 Features

This application models three main components:

- 🎵 **Music Player**
  - Play music
  - Pause music
  - Select a song

- 📞 **Telephone Device**
  - Make calls
  - Answer calls
  - Start voicemail

- 🌐 **Web Browser**
  - Display web pages
  - Open new tabs
  - Refresh pages

---

## 🧠 Concepts Applied

- Object-Oriented Programming (OOP)
- Interfaces and implementation
- Encapsulation
- Abstraction
- Polymorphism
- Clean code practices
